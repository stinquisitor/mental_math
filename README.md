# Ментальная арифметика — тренажёр

Статическая страница для тренировки сложения и вычитания на абакусе (соробане).
Генерирует листы примеров по темам и формулам, проверяет ответы, печатает листы
и показывает примеры во флеш-режиме («флеш-анзан», с озвучкой).

## Запуск

```bash
npm start
```

Откройте http://localhost:8765. Нужен любой статический сервер (страница использует ES-модули,
поэтому через `file://` не откроется).

Тесты генератора:

```bash
npm test
```

## Что умеет генератор

| Настройка | Значения |
|---|---|
| Тема | Просто · МТ (младшие товарищи, формулы на 5) · СТ (старшие товарищи, формулы на 10) · СТ+МТ (комбинированные) |
| Формулы | любой набор формул темы, например только СТ +7; можно разрешить остальные формулы темы и формулы предыдущих тем |
| Разрядность | 1–5 разрядов, одинаковая или разная внутри примера (например, 1–2: первое число двузначное, остальные одно- или двузначные) |
| Чисел в примере | 2–30 |
| Примеров | 1–200 |
| Действия | сложение и вычитание / только сложение / только вычитание |
| Частота формулы | тренируемая формула встречается в каждом примере не реже 1–4 раз |

Обозначение «1Д4Р» — как в сборниках: однозначные числа, 4 числа в примере; при разной разрядности — «1–2Д4Р».

Каждое число проверяется по модели абакуса (`js/abacus.js`): действие на каждой спице
классифицируется как «просто», МТ, СТ или комбинированная формула, включая переносы
в соседний разряд (49 + 1 → СТ +1 на единицах и МТ +1 на десятках). Поэтому в примере
никогда не появится формула, которую ребёнок ещё не проходил.

Номер варианта и все настройки хранятся в ссылке — по ней откроется тот же самый лист.

## Структура

- `index.html`, `css/style.css` — страница (экран и печать).
- `js/abacus.js` — модель абакуса и генератор, без зависимостей от браузера (можно
  переиспользовать на сервере).
- `js/app.js` — интерфейс: настройки, лист, проверка, флеш-режим.
- `tests/abacus.test.mjs` — тесты на `node:test`.
